# Cybersecurity Notes

A curated, categorized collection of cybersecurity learning resources — from **foundations to advanced topics** across every major subdomain, plus practical **tool usage guides**.

This repo is a **reading index / catalog**. It organizes 70 resources (lecture notes, tutorials, government guidance, and tool guides) into 13 domains so you can learn each area from basics to advanced.

> ⚠️ **Note:** This repository contains only this index — no third-party PDF files are redistributed here, to respect the original authors' copyright. Each entry names the source so you can find the material from its publisher.
